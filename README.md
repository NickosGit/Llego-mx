# ¿Llego?

Mobile-first web app for one rider on one route: what time to leave to ride the Ruta 120 seated and still reach the Cámara de Diputados by 7:00.

All trip data in this build is simulated and labeled on screen. The spec is in `docs/PACKET.md`.

```bash
npm install
npm run dev
```

Runs on http://localhost:4000. Copy `.env.example` to `.env.local` and fill in the Supabase URL and anon key.
